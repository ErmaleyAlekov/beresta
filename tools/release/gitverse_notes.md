
---

**Где собраны файлы этого релиза.** SDK для Linux x86_64 и aarch64 собраны на Gitverse в Astra Linux SE 1.7 (GCC 8.3, glibc 2.28; работают на системах с glibc 2.17 и новее), модульные тесты пройдены на обеих архитектурах (aarch64 — в qemu). SDK для Windows x86_64 (`*-windows-x86_64-mingw.zip`) собран на Gitverse компилятором MinGW-w64. SDK для macOS и Windows ARM64, пакеты npm, PyPI, NuGet, Maven и WebAssembly взяты из релиза GitHub: это те же файлы, что опубликованы в реестрах пакетов.

**Where the files of this release are built.** The Linux x86_64 and aarch64 SDKs are built on Gitverse in Astra Linux SE 1.7 (GCC 8.3, glibc 2.28; they run on systems with glibc 2.17 and newer), the unit tests pass on both architectures (aarch64 in qemu). The Windows x86_64 SDK (`*-windows-x86_64-mingw.zip`) is built on Gitverse with the MinGW-w64 compiler. The macOS and Windows ARM64 SDKs and the npm, PyPI, NuGet, Maven and WebAssembly packages are taken from the GitHub release: they are the same files that are published to the package registries.
