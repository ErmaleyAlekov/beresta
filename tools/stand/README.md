# Проверочный стенд «Берёсты»

Стенд для эксперта (в том числе при проверке для реестра российского ПО): одной командой собирает библиотеку **из исходного текста**, прогоняет модульные тесты и демонстрационные программы и записывает отчёт. Готовые бинарники не используются, поэтому стенд работает и там, где готовые сборки Linux не запускаются (они требуют glibc 2.35+, а, например, в Astra Linux SE 1.7 — glibc 2.28).

## Требования к стенду

| Что | Требование |
|---|---|
| ОС | Linux x86_64 или ARM64: Astra Linux, РЕД ОС, ALT, Debian, Ubuntu и др.; также macOS и Windows (Git Bash / MSYS2) |
| Компилятор | C++17: GCC 9+ или Clang 9+ (на GCC 8 сборка не проверялась — стенд предупредит) |
| Сборка | GNU Make (предпочтительно) или CMake 3.x |
| Библиотеки | статическая `libstdc++` (для динамической библиотеки на Linux); сторонних библиотек не нужно |
| Оболочка | любая POSIX `sh` (dash, bash, busybox ash) |
| Сеть | не нужна |
| Время | несколько минут на полную сборку (зависит от числа ядер) |

Установка инструментов:

| ОС | Команда |
|---|---|
| Astra Linux, Debian, Ubuntu | `sudo apt-get install build-essential make` |
| РЕД ОС, другие RHEL-подобные | `sudo dnf install gcc-c++ make libstdc++-static` |
| ALT | `apt-get install gcc-c++ make` и пакет `libstdc++<версия GCC>-devel-static` |

## Запуск

Из корня распакованного исходного текста (архив исходного кода релиза или `git clone`):

```bash
sh tools/stand/run_stand.sh
```

Переменные: `CXX`, `CC` — выбрать компилятор (например, `CXX=clang++ CC=clang sh tools/stand/run_stand.sh`), `STAND_LANG=en` — сообщения на английском.

## Что делает

1. Записывает окружение: ОС (`/etc/os-release`), ядро, версию glibc, компилятор, make, cmake.
2. Проверяет поддержку C++17 (компиляция и запуск пробной программы с `std::optional`, `std::string_view`, `std::filesystem`).
3. Проверяет, что компоновщик находит статическую `libstdc++`.
4. Собирает библиотеку: `make all` (или CMake с тестами и примерами, если make нет).
5. Запускает модульные тесты: `make test` (или `ctest`).
6. Запускает демонстрационные программы на C++ и C.

Итог — в `stand_report.txt` (строки `[OK]` / `[FAIL]` по шагам, время, хвост журнала при ошибке), полные журналы шагов — в `stand_logs/`. Код возврата 0 — все шаги пройдены.

## Устройство

| Файл | Назначение |
|---|---|
| `run_stand.sh` | точка входа: порядок шагов |
| `lib/messages.sh` | каталог сообщений (русский и английский) |
| `lib/report.sh` | отчёт и запуск шагов с журналами |
| `lib/environment.sh` | поиск инструментов, описание окружения, проверки C++17 и `libstdc++` |
| `lib/build.sh` | сборка, тесты, демонстрационные программы |
