## Разбор

Скрипт описания релиза различает полные номера версий. Gitverse создаёт релиз только после HTTP 404, хранит ответы и ZIP во временном каталоге и очищает его после успеха и ошибки. Для зеркала GitHub файлы загружаются во временный каталог. Проверяются SHA-256 из API, а при наличии манифеста — также его состав и суммы. Выпуск публикует SHA256SUMS.txt для резервного пути через HTML.

Действия в GitHub CI и release закреплены SHA коммитов соответствующих тегов. Для нативных сборок добавлена защита стека, в оптимизированных сборках Linux включён FORTIFY, при компоновке Linux — RELRO и NOW, в MSVC — Control Flow Guard. macOS fclean убирает копии для обеих архитектур. Ручная проверка выявила сценарии, отсутствовавшие в обычной сборке. В CI добавлены автономные регрессии релизных скриптов и проверка очистки после make universal.
