# Журнал изменений

Русский | [English](CHANGELOG.en.md)

Версии следуют [семантическому версионированию](https://semver.org/lang/ru/). Раздел версии
целиком попадает в описание релиза на GitHub и Gitverse.

## 2.1.3 — 2026-10-20

Сборка из исходного текста на российских ОС и проверочный стенд для эксперта.

### Сборка

- GCC 8 (Astra Linux SE 1.7): `std::filesystem` подключается из `libstdc++fs` — Makefile и CMake
  добавляют `-lstdc++fs` сами, если версия GCC ниже 9.
- glibc < 2.34 (Astra Linux SE 1.7, РЕД ОС 7.3): модульные тесты компонуются с `-pthread`
  (в CMake — `Threads::Threads`).

### Проверочный стенд

- `sh tools/stand/run_stand.sh` — одной командой собирает библиотеку из исходного текста, запускает
  модульные тесты и демонстрационные программы и пишет отчёт `stand_report.txt` (ОС с версией, glibc,
  компилятор, итог по шагам и число пройденных тестов). Описание — `tools/stand/README.md`.
- Стенд пройден (211 из 211 тестов) на Astra Linux SE 1.7 и 1.8, ALT p10 и p11, РЕД ОС 7.3 и 8.

### Документация

- Документы для реестра российского ПО (`docs/registry/`) и сайт продукта (`site/`).

## 2.1.2 — 2026-10-20

Проверка XML Schema по итогам W3C XML Schema Test Suite: **93,6 % → 96,2 %** применимых случаев.

### Регулярные выражения XSD

- Категории `\p{..}` и блоки `\p{Is..}` / `\P{..}` — по Unicode 3.1 (версия, на которую ссылается
  XSD 1.0), из собственных таблиц без ICU; генератор `tools/unicode/generate_unicode_tables.py`.
- `\d` = `Nd`, `\w` — всё, кроме `P`, `Z`, `C`; `\i` и `\c` — по приложению B XML 1.0.
- Строгий синтаксис XSD 1.0: неизвестные экранирования (`\x41`, `\A`, `\b`, `\1`), обратный диапазон,
  пустой класс и `[` без экранирования внутри класса — ошибка схемы; `\p{Cs}` и неизвестные имена — тоже.
- XSTS 93,6 % → 95,7 %, в группе MS-Regex провалов нет (было 776).

### Значения и подстановочные атрибуты

- Частичный порядок `xs:duration` (3.2.6.2) в фасетах-границах.
- `xs:anyAttribute` по 3.4.2 / 3.10.6: пространства имён, пересечение, объединение при расширении,
  lax / strict по глобальным атрибутам, cvc-complex-type.5; `xs:anyType` — встроенный составной тип.
- `fixed` у смешанного содержимого, `xsi:nil` (cvc-elt.3), ID / IDREF у атрибутов по умолчанию,
  `xs:all` с `maxOccurs="0"`.

### Ограничения идентичности

- Поля `xs:key` / `xs:unique` видят атрибуты `default` / `fixed`, которых нет в экземпляре, — и в потоке,
  и при проверке по дереву.
- Поле на элемент составного типа без простого содержимого — ошибка `KEY_FIELD_COMPLEX`,
  на атрибут без типа (skip / lax) — `KEY_FIELD_UNTYPED`.
- `QName` / `NOTATION` в ключах сравниваются по паре «URI + локальное имя».
- XSTS 95,7 % → 96,2 %.

### Выпуск

- Релиз выходит одновременно на GitHub и Gitverse; пакеты в реестрах (npm, PyPI, NuGet, Maven Central)
  публикуются только из GitHub. Порядок — в [docs/building.md](docs/building.md#выпуск-версии).
