XML-библиотека «Берёста»

Программа для ЭВМ «XML-библиотека „Берёста“ (beresta)» — библиотека на языке C++17 без единой сторонней зависимости: разбор и проверка XML, дерево документа (DOM), потоковая обработка (SAX), DTD, XML Schema, XPath 1.0, XInclude и запись XML. Через плоский Си-интерфейс ей пользуются программы на C, Java, C#, Python, Node.js и WebAssembly.

  • Версия 2.1.3
  • Лицензия MIT
  • Бесплатно

Возможности

Разбор XML 1.0

100 % применимых случаев W3C XML Conformance Test Suite, пространства имён, восемь кодировок, включая windows-1251, KOI8-R и IBM866.

DOM и SAX

Компактное дерево с переносом узлов между документами и потоковый разбор, память которого не зависит от размера документа.

DTD и XML Schema

Проверка по DTD и XSD 1.0 с ключами, группами замены и утверждениями xs:assert из XSD 1.1 — по дереву, при разборе или потоком без дерева.

XPath 1.0

Все 13 осей и 27 функций, переменные, префиксы, скомпилированные выражения для многократного вызова из разных потоков.

Безопасность по умолчанию

Нет загрузки внешних ресурсов без разрешения (XXE, SSRF), лимиты на сущности и глубину, линейное время регулярных выражений.

Шесть языков

C++, C, Java (Project Panama), C# (P/Invoke), Python (ctypes), Node.js (Node-API) и WebAssembly из одного ядра.
