# Code of Conduct

[Русский](CODE_OF_CONDUCT.md) | English

This code of conduct applies to all spaces in the Beresta project: in issues, pull requests, discussions, wikis, and comments on GitHub and Gitverse, as well as wherever someone publicly represents the project. It is based on the ideas of [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Our Commitment

We want participation in the project to be welcoming and harassment-free for everyone — regardless of age, appearance, disability, nationality, race, religion, gender, gender identity, sexual orientation, experience, education, and social status.

## How We Behave

- Respect the interlocutor and their time; argue about the code and solutions, not about people.
- Accept constructive criticism and criticize constructively ourselves: with an example, a reference to a standard, or a test.
- Admit our mistakes and learn from them.
- Help newcomers: a question about how to build is just as appropriate as an XSD 1.1 analysis.
- Write in Russian or English — both languages are equal in the project.

## What Is Not Acceptable

- Insults, derogatory comments, personal attacks, trolling.
- Harassment — public or in private messages.
- Publishing of others' personal data (addresses, phone numbers, correspondence) without permission.
- Sexualized statements and images, unwanted attention.
- Any other behavior that a reasonable person would consider inappropriate in a professional environment.

## Responsibility and Enforcement

Project maintainers monitor adherence to the code of conduct and have the right to delete or edit comments, commits, code, issues and wiki pages that do not comply with it, as well as to temporarily or permanently limit participation.

Report a violation to the maintainer: on GitHub — through a private message ([Security → Report a vulnerability](https://github.com/ErmaleyAlekov/beresta/security/advisories/new) is suitable for this as well), on Gitverse — with an issue titled "Code of conduct: requesting a contact" without details. Reports are handled confidentially, and the message author is protected from retaliation.

Consequences are proportional to the violation: warning → temporary participation restriction → permanent blocking.
